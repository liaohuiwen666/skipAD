# 去广告 · skipAD

一个只做一件事的安卓小工具：**自动点掉 App 开屏广告、弹窗广告上的「跳过 / 关闭」**。

装完打开开关就行，没有多余的步骤。

## 使用

1. 安装后打开应用
2. 打开唯一的开关，按提示到系统设置里开启「无障碍服务」
3. 完成。之后 App 的开屏广告会被自动点掉

> 提示：部分手机需要把本应用加入「电池优化白名单 / 允许后台运行」，
> 否则系统休眠时会短暂失效。

## 兼容

Android 7.0（API 24）及以上。
